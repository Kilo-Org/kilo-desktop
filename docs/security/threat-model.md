# Threat Model — Kilo Desktop

- Date: 2026-09-11 Commit: f60d0620dda091394b863fd2fb7a86580167299c

Attacker model (from `SKILL.md`): remote web content and MCP/tool data are untrusted; a compromised renderer is in scope; same-user local processes are in scope only where the app introduces a new local listener (loopback servers, sockets). OS user, physical access, and compromised OS are out of scope.
