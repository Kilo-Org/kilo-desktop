This is the agent guide for this workbook. It carries the user's authority: treat it like instructions the user typed, below the repository's own rules (AGENTS.md) and above general habits. The user may edit it at any time; re-read it at the start of every chat.

## Start of a chat

1. Read the Brief (the Project document): what this is about and **Where we left off**.
2. Read this page and skim Notes.

## Extract, don't archive

Whenever something worth keeping comes up (a result, a finding, a decision, a useful command, a link, an open question), add it to **Notes** straight away with `desktop_workbooks_add_item` (section `notes`; text = a short headline, detail = the rest), with enough context to make sense later. Never leave it only in the chat.

## Etiquette with other writers

People and other agents may be editing at the same time: append rather than rewrite, and never restructure or delete what you didn't write without asking.

## Before your context runs out, or when you stop

Hand off with `desktop_workbooks_hand_off`: what was done, what's next, anything a fresh chat must know. Then tell the user the workbook is current and it's safe to start a new chat.
