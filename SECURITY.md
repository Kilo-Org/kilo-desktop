# Security

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues, pull requests, or
discussions.

Email your findings to [security@kilo.ai](mailto:security@kilo.ai). Include the Kilo
Desktop version, your operating system, and the steps to reproduce the issue. We will
acknowledge your report, keep you informed as we work on a fix, and may ask you for more
information.

For more details, see the [Kilo Security Disclosure](https://kilo.ai/security) page.

## AI-generated reports

We do not accept AI-generated security reports. We receive many of them and don't have the
resources to review them all. Submitting one will result in a ban from the project.
