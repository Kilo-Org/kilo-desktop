# Reading Mode telemetry

Events sent by Reading Mode: Focus, the reading control (Aa) and Saved. They
go through `kernel/telemetry` like every plugin event: only after the person
allowed data collection, declared as `kernel/telemetry-event` in the sending
plugin's manifest.

## Rules

- **No content.** No reply or saved text, chat or session titles, paths,
  search queries or ids are ever sent.
- **Coarse values.** Counts use the buckets `0`, `1`, `2-5`, `6-20`, `21+`;
  lengths `0`, `1-20`, `21-100`, `101-500`, `501+`; ages `<1h`, `<1d`, `<7d`,
  `<30d`, `30d+`; durations `<10s`, `<1m`, `<5m`, `<20m`, `20m+`. Percentages
  are rounded to tens; seconds are capped (4 hours in Focus, a day since the
  last exit). Everything else is a boolean or one of a fixed set of names.
- **Local counts stay local.** First-time and lifetime fields are derived from
  `kilo.shell/reading-usage` (main, kv), whose raw values are never sent.
- **Excerpts are matched by hash.** Text copied in Focus is remembered in the
  window only as a 32-bit hash for five minutes, to notice it being pasted
  into a composer.

## Events

| Event                        | Sender                        | When                                                                     | Properties                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------- | ----------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Focus Entered                | kilo.chat, kilo.files         | Focus opens                                                              | `surface` (reply · plan · file), `source` (rail · shortcut · reading-control · palette), `isFirstTime`, `lifetimeVisits` (count), `daysSinceLastVisit` (null the first time), `secondsSinceLastExit`, `blockCount` (count), `startBlockPct`, `streaming`, `readingThemeApplied`, `movesWith`, `dimming`                                                                                                             |
| Focus Exited                 | kilo.chat, kilo.files         | Focus closes, however it closed                                          | `surface`, `exitReason` (escape · exit-button · shortcut · reading-control · session-switched · pane-closed · content-gone · window-closed · other), `duration` (bucket), `durationSeconds`, `activeSeconds`, `blocksVisited`, `maxBlockPct`, `movesByKeys`, `movesByScroll`, `movesByPointer`, `settingsChanged`, `savesCreated`, `copies`, `typingAttempts`, `findAttempts` (counts), `replyFinishedWhileReading` |
| Focus Entry Failed           | kilo.chat, kilo.files         | ⌘⇧F with nothing to read                                                 | `reason` (no-content · unavailable · secondary-window)                                                                                                                                                                                                                                                                                                                                                              |
| Reading Control Opened       | kilo.chat, kilo.files         | The Aa popover opens                                                     | `surface` (chat · plan · file · focus)                                                                                                                                                                                                                                                                                                                                                                              |
| Reading Setting Changed      | kilo.chat, kilo.files         | A reading setting changes                                                | `setting` (theme · mode · text-size · line-spacing · moves-with · dimming · reset), `value` (theme id or `app` · mode · step · spacing index · option · dimming to tens · null), `surface`                                                                                                                                                                                                                          |
| Reading Preferences Snapshot | kilo.shell                    | Once a day, once collection is allowed                                   | `themeId` (or `app`), `mode`, `textSizeStep`, `lineSpacing`, `movesWith`, `dimming`, `isDefault`                                                                                                                                                                                                                                                                                                                    |
| Focus Round Trip             | kilo.chat                     | Back in Focus within 10 minutes of leaving, after sending a prompt there | `secondsInChat`, `promptsSent` (count), `copiedInFocus`                                                                                                                                                                                                                                                                                                                                                             |
| Focus Excerpt Used In Prompt | kilo.chat                     | Text copied in Focus is pasted into a composer within 5 minutes          | `secondsSinceCopy`, `length` (bucket), `surface`                                                                                                                                                                                                                                                                                                                                                                    |
| Saved Item Added             | kilo.chat                     | Text saved or a chat bookmarked                                          | `kind` (text · chat), `surface` (chat · focus), `origin` (selection-menu · bookmark-button), `selectionLength` (bucket), `countInChat` (count), `isFirstTime`, `lifetimeCount` (count)                                                                                                                                                                                                                              |
| Saved Item Removed           | kilo.chat, kilo.work-sessions | An item leaves Saved                                                     | `kind` (text · chat · output), `via` (highlight-menu · bookmark-button · saved-page · undo), `ageBucket`                                                                                                                                                                                                                                                                                                            |
| Saved Toast Action           | kilo.chat                     | View or Undo on the "Added to Saved" / "Removed from Saved" toast        | `action` (view · undo), `kind`                                                                                                                                                                                                                                                                                                                                                                                      |
| Selection Menu Used          | kilo.chat                     | Save, Copy or Remove in the selection menu                               | `action` (save · copy · remove), `surface` (chat · focus)                                                                                                                                                                                                                                                                                                                                                           |
| Saved Action Failed          | kilo.chat, kilo.work-sessions | Adding, removing, restoring or opening an item failed                    | `action` (add · remove · restore · open), `kind`                                                                                                                                                                                                                                                                                                                                                                    |
| Saved Page Opened            | kilo.work-sessions            | The Saved page opens                                                     | `source` (sidebar · toast-view · palette), `itemCount`, `sessionCount` (counts)                                                                                                                                                                                                                                                                                                                                     |
| Saved Item Opened            | kilo.work-sessions            | A row on the Saved page is clicked                                       | `kind`, `ageBucket`, `sameSession`, `resolved` (exact · message · unavailable), `position` (capped at 50)                                                                                                                                                                                                                                                                                                           |
| Saved Page Searched          | kilo.work-sessions            | Once per search, after typing settles                                    | `queryLength` (bucket), `results` (count)                                                                                                                                                                                                                                                                                                                                                                           |
| Saved Page Filtered          | kilo.work-sessions            | A filter chip is chosen                                                  | `filter` (all · chats · text)                                                                                                                                                                                                                                                                                                                                                                                       |

`kilo.chat/src/web/reading/reading-telemetry.ts` types kilo.chat's events; a
unit test keeps that list equal to its manifest's declarations.
